📊 Análise de Transações Financeiras (Excel)
🎯 Objetivo do Projeto

Realizar uma análise exploratória de transações financeiras, com foco em faturamento, status das transações e métodos de pagamento, a fim de identificar padrões, pontos de atenção e oportunidades de melhoria para o negócio.

O projeto simula um cenário real de análise financeira aplicada à tomada de decisão baseada em dados.

🛠️ Ferramentas Utilizadas

Microsoft Excel

Tratamento e limpeza de dados

Tabelas Dinâmicas

Gráficos analíticos

Fórmulas para cálculo de métricas financeiras

📁 Estrutura da Planilha

A planilha está organizada nas seguintes abas:

transacoes_financeiras_limpa
Base de dados tratada contendo as transações financeiras.

faturamento total completo
Análise do faturamento total considerando transações concluídas.

maior gasto da empresa
Identificação das transações de maior valor.

método de pagamento com canc
Análise dos métodos de pagamento com maior volume de cancelamentos.

🧾 Descrição dos Dados

A base de dados contém as seguintes informações:

ID da transação

Data da transação

Valor

Moeda

Tipo de transação (Deposit, Withdrawal, Transfer)

Status da transação (Completed, Cancelled, Pending, Failed)

Categoria

Método de pagamento

Taxa aplicada

Valor total da transação

📌 Métricas Analisadas

Faturamento total das transações concluídas

Volume de transações por status

Identificação das transações de maior valor

Cancelamentos por método de pagamento

Distribuição das transações por categoria

📈 Principais Insights

O faturamento considera apenas transações com status Completed, garantindo maior precisão financeira.

Determinados métodos de pagamento apresentam maior incidência de cancelamentos, indicando possíveis pontos de atenção operacional.

As transações de maior valor ajudam a identificar impactos relevantes no faturamento total.

A análise por categoria permite entender melhor o perfil das transações realizadas.
